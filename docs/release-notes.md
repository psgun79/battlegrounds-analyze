Python 설치 없이 실행하는 Windows x64용 전장 복기 로거입니다.

1. 아래 Assets에서 `battlegrounds-review-logger-0.4.2-windows-x64.zip`을 다운로드합니다.
2. ZIP 전체를 압축 해제하고 `bg-review.exe`를 더블클릭합니다.
3. 처음이라면 메뉴 **2**로 게임 로그 설정 후 하스스톤을 재시작합니다.
4. 메뉴 **1**로 기록을 시작합니다. 로그 위치는 Enter로 자동 검색합니다.
5. 경기 종료 후 Ctrl+C로 기록을 멈추고 메뉴 **3**으로 복기 파일을 확인합니다.

`_internal` 폴더를 포함해 압축 해제한 폴더 전체를 유지하세요.
`Source code` ZIP은 개발용이며 실행 파일이 포함되지 않습니다.

기록은 `%LOCALAPPDATA%\BattlegroundsReview\output`에 저장됩니다.
일반 복기에는 해당 경기의 `.review.md`와 동봉한 AI 복기 프롬프트를 사용하세요.

이 버전은 솔로 전장용이며, 게임 프로세스와 독립적으로 `Power.log`를 읽습니다.
공개 카드 데이터는 내려받을 수 있지만 경기 로그는 업로드하지 않습니다.

프로그램은 코드 서명되지 않았습니다. ZIP 무결성 확인용 SHA256 파일을 함께 제공합니다.
Windows 경고가 나오면 배포 출처를 확인하세요. 보안 기능을 끄지 마세요.

변경 사항: 더블클릭 메뉴, Windows 실행 파일 빌드, ZIP 실행 검증, 태그 기반 자동 배포 추가.
