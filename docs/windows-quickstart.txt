전장 복기 로거 — Windows 실행 파일 사용 안내

Windows x64용입니다. Python, Git, HDT를 설치하지 않아도 됩니다.

1. ZIP 파일을 전부 압축 해제합니다.
2. bg-review.exe를 더블클릭합니다.
3. 처음 사용한다면 메뉴 2로 게임 로그 설정을 켠 후 하스스톤을 재시작합니다.
   기존 log.config가 있으면 백업합니다. 게임 실행 파일은 수정하지 않습니다.
4. 메뉴 1로 기록을 시작합니다. 로그 위치는 Enter를 누르면 자동 검색합니다.
   찾지 못하면 하스스톤 설치 폴더 아래 Logs 폴더의 전체 경로를 입력하세요.
5. 창을 열어 둔 채 솔로 전장을 플레이합니다.
6. 게임 종료 후 Ctrl+C로 기록을 멈추고, 메뉴 3으로 결과 폴더를 엽니다.
7. 해당 판의 .review.md와 AI-복기-프롬프트.md 내용을 AI에 전달하세요.
8. 메뉴에서 Q를 입력하면 종료됩니다.

결과 위치: %LOCALAPPDATA%\BattlegroundsReview\output
업데이트: 새 버전을 다른 폴더에 압축 해제하세요. 기존 기록은 위 위치에 남습니다.
제거: 실행을 종료한 뒤 압축 해제한 프로그램 폴더를 삭제하세요.
기록과 카드 캐시는 별도이며 자동 삭제되지 않습니다.

주의: bg-review.exe 옆의 _internal 폴더가 반드시 필요합니다.
exe만 복사하거나 ZIP 내부에서 바로 실행하지 마세요.
서명되지 않은 배포 파일이므로 Windows에서 게시자 확인 경고가 나타날 수 있습니다.
배포 페이지의 출처와 SHA256을 확인하세요. 보안 기능을 끌 필요는 없습니다.

솔로 전장용이며 듀오·재접속·중간부터 기록한 경기에는 누락이 생길 수 있습니다.
카드 설명 보강을 위해 공개 카드 데이터를 내려받을 수 있으며 경기 로그는 업로드하지 않습니다.
원본 로그와 상세 진단 파일에는 플레이어 이름 등이 포함될 수 있습니다.

고급 사용 (PowerShell):
  .\bg-review.exe --help
  .\bg-review.exe watch --log-root 'D:\Games\Hearthstone\Logs'
  .\bg-review.exe watch --offline
  .\bg-review.exe replay 'C:\logs\Power.log' --offline
