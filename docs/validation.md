- 모든 영웅, 전투 효과, 재접속, 강제 종료, 실제 로그 회전 조합을 실게임에서 검증한 것은 아님. 바이트 분할/잘림/교체/중단은 자동 테스트로 검증.
- 실제 게임 렌더링 시점과 로그 발생 시점의 일치는 녹화로 대조하지 않음. 중간 효과 상점을 플레이어가 클릭할 수 있었다고 가정하면 안 됨.
- 하스스톤의 FPS/프레임 지연을 계측하지 않음. 게임 외부 프로세스이며, 새로운 로그가 없을 때 전체 export를 반복하지 않도록 구현. CPU/메모리 영향의 정확한 수치는 아직 없음.
- 관전/듀오/메모리 전용 특수 상점, MMR, 종족 제한, 시뮬레이터 승률 미지원.
- 0.4 검증에서는 build 250339 카드 DB를 사용. 빌드가 다르거나 매핑/표시 변수가 미확인인 항목, 기본 스탯 등 로그에 없는 정보는 여전히 누락될 수 있음.
- 누락된 BLOCK_END의 stateAfter는 다음 확실한 경계까지의 관측 상태이며 정확한 종료 시점과 다를 수 있음.
- 전체 로비 보드의 동시 관측이 없으므로 로비 평균 성장 속도/전투 EV 수치는 제공하지 않음.
